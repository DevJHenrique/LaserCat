# Code of conduct

LaserCat is built by people with different backgrounds, languages, machines, and levels of experience. Everyone taking part in issues, pull requests, discussions, and reviews is expected to help keep the project welcoming and useful.

## Expected behavior

- Be respectful and assume good intent. Critique code and ideas, not people.
- Be specific and evidence-based: steps, logs, images, and test results beat opinions.
- Welcome newcomers and questions in English or Portuguese; maintainers may answer in English so the record stays searchable.
- Respect safety. Never pressure anyone to run untested code on physical lasers or to bypass interlocks.
- Credit others' work and respect licenses.

## Unacceptable behavior

- Harassment, insults, discriminatory language, or personal attacks.
- Publishing others' private information, artwork, or machine/network settings without permission.
- Sustained disruption of discussions, or spam.
- Deliberately submitting code or instructions that would make a machine unsafe.

## Enforcement

Maintainers may edit or remove comments, close threads, or restrict participation when this code is not followed. Report problems through the private channel described in [SECURITY.md](SECURITY.md) or by asking a maintainer for a private contact in an issue without sensitive details. Reports are handled confidentially and as promptly as maintainer availability allows.
