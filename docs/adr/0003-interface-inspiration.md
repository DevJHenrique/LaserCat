# ADR 0003 — Interface inspiration and attribution

- Status: accepted for the original UX direction; attribution scope narrowed by [ADR 0004](0004-license-and-documentation.md)
- Original date: 2026-10-17
- Editorial update: 2026-10-18

## Context

The requested workflow uses a visual bed, object/process panels, transform controls, and separate preparation, preview, and device modes. Implementation remains Rust/egui.

## Decision

Use that workflow as a design reference while implementing original UI code, icons, and documentation. Acknowledge interface inspiration in one short README sentence. Repeated upstream histories and branding explanations are unnecessary.

## Consequences

LaserCat retains its own product identity. Reused third-party material always requires origin/license review. Current project licensing is governed by ADR 0004; previous licensing grants remain valid for their versions.
