# Security

LaserCat is in early development. The current version receives fixes; older releases do not have a separate maintenance policy.

Treat project files, SVG, and images as untrusted input. Useful reports include the version, a minimal reproduction, and the impact, without private artwork, credentials, or network settings.

If [Private vulnerability reporting](https://github.com/DevJHenrique/LaserCat/security) is enabled on the GitHub repository, use **Security → Report a vulnerability** for sensitive issues. No security email address or alternative private channel is currently configured in this repository. If that option is unavailable, request a private contact channel in an issue without posting sensitive details.

Software controls depend on communication and the controller; they do not replace the machine's physical stop controls. Movement/emission reports must distinguish simulator and hardware observations and describe the conditions checked by the operator.
